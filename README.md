# Newton-Raphson Web Calculator

واجهة ويب عربية لحساب جذور المعادلات بطريقة نيوتن–رافسون.

## التشغيل
افتح `index.html` مباشرة في المتصفح.

## النشر على GitHub Pages
1. أنشئ مستودعاً جديداً على GitHub.
2. ارفع الملفات `index.html`, `style.css`, `script.js`, `README.md` إلى جذر المستودع.
3. افتح Settings > Pages.
4. اختر Deploy from a branch ثم `main` و`/(root)` واضغط Save.
5. سيظهر رابط المشروع بعد اكتمال النشر.

## مثال
- f(x) = x^3 - x - 2
- f'(x) = 3*x^2 - 1
- x0 = 2
- بعد 3 خطوات تكون النتيجة التقريبية 1.521379806.
